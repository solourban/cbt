# CBT 서비스 오류 기록 템플릿

## 사용 원칙

오류를 발견하면 즉시 코드 수정하지 않고 먼저 기록한다.
동일 유형 오류를 모아 채점 엔진, 데이터, 화면, 저장, 배포 문제로 분류한 뒤 일괄 수정한다.

---

## 오류 기록 양식

```txt
번호:
발견일:
테스트 환경: 모바일 / PC / 태블릿
브라우저:
구분: 기출 / 모의고사 / 약점집중 / 데일리드릴 / OX / 플래시카드 / 검색 / 북마크 / 오답노트 / 통계 / 유료인증 / 광고 / 배포
위치:
입력값:
증상:
예상 동작:
실제 동작:
재현 방법:
우선순위: P0 / P1 / P2 / P3
추정 원인: 데이터 / 채점함수 / 화면상태 / localStorage / 배포 / 알 수 없음
처리 상태: 미확인 / 재현됨 / 수정중 / 수정완료 / 보류
비고:
```

## 예시

```txt
번호: BUG-001
발견일: 2026-05-18
테스트 환경: PC
브라우저: Chrome
구분: 기출
위치: 2016년 기출복원 1번
입력값: 수용, 사용방식, 환지방식
증상: 공란 상태에서는 채점되지만 텍스트 입력 후 채점 버튼을 누르면 반응 없음
예상 동작: 부분점수 또는 오답 피드백 표시
실제 동작: 아무 반응 없음
재현 방법:
1. 2016년 기출복원 진입
2. 1번 문제에 답 입력
3. 채점 버튼 클릭
우선순위: P1
추정 원인: 채점함수
처리 상태: 재현됨
비고: 단답형 grS 오류 의심
```

## 우선순위 기준

### P0. 즉시 수정

서비스 전체가 열리지 않거나, 문제풀이 자체가 불가능한 오류.

예시:

- 첫 화면 로딩 실패
- questions.js 로딩 실패
- 모든 문제 채점 불가
- Vercel 배포 실패

### P1. 1차 완성 전 수정

핵심 기능 중 하나가 막히는 오류.

예시:

- 특정 유형 채점 버튼 무반응
- 전체채점 실패
- 모의고사 생성 실패
- 연도별 기출 진입 실패

### P2. 1차 완성 후 보완

사용은 가능하지만 품질을 떨어뜨리는 오류.

예시:

- 특정 답안 인정범위 부족
- 해설 문구 어색함
- 통계 일부 부정확
- 광고 위치 불편

### P3. 장기 개선

운영형 서비스 전환 때 함께 손볼 항목.

예시:

- 관리자 페이지 필요
- Supabase 저장 전환
- UI 개선
- 자동결제 연동

## 오류 유형 분류

| 유형 | 설명 | 예시 |
|---|---|---|
| 데이터 오류 | 문제 객체의 필드 구조·정답·키워드 문제 | keywords 누락, steps 구조 오류 |
| 채점함수 오류 | 답 입력 후 함수가 멈추거나 오판정 | 텍스트 입력 시 채점 무반응 |
| 화면상태 오류 | 페이지 이동, 버튼 상태, 렌더링 문제 | 다음 문제 이동 실패 |
| 저장 오류 | localStorage 기록 문제 | 오답노트 미저장 |
| 배포 오류 | Vercel 빌드/배포 문제 | dist 파일 누락 |
| 정책/운영 오류 | 유료 잠금, 광고, 이용 안내 문제 | 잠금창 미표시 |

---

## 1차 QA 완료 기준

다음 조건을 만족하면 1차 QA를 완료로 본다.

1. P0 오류가 없다.
2. P1 오류가 모두 기록되어 있다.
3. 핵심 흐름은 최소 1회 이상 끝까지 수행했다.
4. 기출, 모의고사, 드릴, OX, 플래시카드, 검색, 북마크, 오답노트 중 치명적 막힘이 없다.
5. 배포 화면에서 신규 기출 연도가 표시된다.
