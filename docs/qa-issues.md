# CBT 서비스 QA 이슈 장부

## 목적

`qa-run-001.md`는 테스트 실행 과정 전체를 기록하는 로그이고, 이 문서는 발견된 오류만 따로 모아 관리하는 이슈 장부다.

오류는 즉시 수정하지 않고 우선 이곳에 누적한다. P0/P1 오류가 모이면 유형별로 묶어 일괄 수정한다.

---

## 이슈 요약

|---|---|---|---|---|---|---|
| BUG-001 | P1 | 기출 / 단답형 채점 | 2016년 기출복원 1번 | 텍스트 입력 시 채점 무반응 | 채점함수 | 재현됨 |

## BUG-001. 2016년 기출복원 1번 텍스트 입력 시 채점 무반응

```txt
번호: BUG-001
발견일: 2026-05-18
테스트 환경: PC
브라우저: Chrome 추정
구분: 기출 / 단답형 채점
위치: 2016년 기출복원 1번, 도시개발사업 시행방식 3가지
입력값: 수용, 사용방식, 환지방식
증상: 공란 상태에서는 채점되지만 텍스트 입력 후 채점 버튼을 누르면 반응 없음
예상 동작: 부분점수 또는 오답 피드백 표시
실제 동작: 아무 반응 없음
재현 방법:
1. 배포 화면 접속
2. 2016년 기출복원 진입
3. 도시개발사업 시행방식 문제에 텍스트 입력
4. 채점 버튼 클릭
우선순위: P1
추정 원인: 채점함수
처리 상태: 재현됨
비고: 답안 인정범위 문제가 아니라 텍스트 입력 시 단답형 채점 함수가 중단되는 문제로 의심
```

---

## 우선순위 기준

### P0

서비스 전체가 열리지 않거나, 모든 문제 풀이가 불가능한 오류.

### P1

핵심 기능 중 하나가 막히는 오류. 1차 완성 전 수정 대상.

### P2

사용은 가능하지만 품질을 떨어뜨리는 오류. 1차 완성 후 보완 대상.

### P3

장기 개선 또는 운영형 전환 때 처리할 항목.

## 다음 기록 규칙

새 오류는 아래 형식으로 추가한다.

```txt
| BUG-00X | P0/P1/P2/P3 | 구분 | 위치 | 증상 | 추정 원인 | 상태 |
```

상세 내용은 동일한 번호의 섹션으로 별도 작성한다.

---

## 현재 처리 방침

1. BUG-001은 즉시 단독 수정하지 않는다.
2. 전체 수동 QA를 먼저 진행한다.
3. 유사한 채점 오류가 추가로 발견되면 단답형/서술형/계산형/소문항형으로 묶는다.
4. P0/P1 오류를 우선 핫픽스한다.
5. P2/P3 오류는 1차 완성 이후 보완한다.
