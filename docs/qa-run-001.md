## 목적

이번 QA는 기출 업데이트만이 아니라 CBT 서비스 전체 기능을 대상으로 한다.

## 현재 발견 오류

### BUG-001. 2016년 기출복원 1번 텍스트 입력 시 채점 무반응

GitHub Issue: [#33](https://github.com/solourban/cbt/issues/33)

관련 PR: [#38](https://github.com/solourban/cbt/pull/38)

```txt
번호: BUG-001
발견일: 2026-05-18
수정 반영일: 2026-06-18
테스트 환경: PC
브라우저: Chrome 추정
구분: 기출 / 단답형 채점
위치: 2016년 기출복원 1번, 도시개발사업 시행방식 3가지
입력값: 수용, 사용방식, 환지방식
증상: 공란 상태에서는 채점되지만 텍스트 입력 후 채점 버튼을 누르면 반응 없음
예상 동작: 부분점수 또는 오답 피드백 표시
실제 동작: 아무 반응 없음
재현 방법:
1. 배포 화면 접속
2. 2016년 기출복원 진입
3. 도시개발사업 시행방식 문제에 텍스트 입력
4. 채점 버튼 클릭
우선순위: P1
추정 원인: 채점함수
처리 상태: 수정 반영 / 배포 재테스트 필요
비고: PR #38에서 BUG-001 회귀 테스트와 정적 빌드용 grS 안전 패치 반영. 실제 배포 화면에서 재테스트 후 이슈 종료 여부 판단
```

## 1차 QA 완료 기준

1. P0 오류가 없다.
2. P1 오류가 목록화되어 있다.
3. 기출, 모의고사, 드릴, OX, 플래시카드, 검색, 북마크, 오답노트 흐름을 최소 1회 이상 실행했다.
4. 채점 무반응 오류는 유형별로 묶어 일괄 수정한다.
5. 신규 기출 연도는 화면에 표시된다.
