# 2011년 도시계획기사 실기 기출 업데이트 인벤토리

## 작업 목적

업로드된 2011년 복원문제 이미지 PDF를 기준으로 2011년 자료를 분류한다.

2011년 자료는 오래된 복원자료이므로 최신 법령 반영 여부를 확인해야 한다. 다만 2011년 4회 일부 문항은 원문 구조와 정답이 비교적 명확하여 `past_exam` 후보 데이터로 관리한다.

## 플랫폼 기준 분류

- `past_exam`: 회차·문항 구조·정답이 명확한 실제 복원 기출 후보
- `mock_exam`: 복원자료와 법령·개념을 바탕으로 만든 모의고사형 문제
- `practice`: 개념 암기, 키워드 반복, 계산 연습용 문제
- `summary`: 문제 풀이 후 보는 핵심정리·해설 콘텐츠

## 원칙

1. 원문 구조와 정답이 명확한 문제만 `past_exam` 후보로 둔다.
2. 법령·제도 개정 가능성이 있는 문제는 `법령검토필요` 태그를 붙인다.
3. 2013~2020 후보와 중복되는 문제는 신규 추가하지 않는다.
4. 복원자료 기반 문제는 `기출복원` 태그를 붙인다.

## 2011년 제4회 기출 복원문제 후보

출처: 업로드 PDF `pdf24_converted.pdf` 1페이지.

### 2011-4-01. 등비급수법 인구추정

- 유형: 계산형
- 주제: 인구추정, 등비급수법
- 조건:
  - 2005년 인구: 450,000명
  - 2010년 인구: 600,000명
  - 5년 단위 증가율 산정
  - 2020년 인구 예측
- 정답 후보:
  - 증가율 r = 약 1.3333
  - 2020년 인구 = 약 1,066,666명 또는 1,066,667명
- 상태: `past_exam` 후보

### 2011-4-02. 용도지역별 면적 산출

- 유형: 계산형/표 작성
- 주제: 장래시가화지역, 용도지역 배분
- 조건:
  - 주거지역: 1인당 35㎡, 공공용지율 20%
  - 상업지역: 주거지역 면적의 10%
  - 공업지역: 상업지역 면적의 30%
- 정답 후보:
  - 주거지역 면적: 계산 필요
  - 상업지역 면적: 주거지역 면적 × 10%
  - 공업지역 면적: 상업지역 면적 × 30%
- 상태: `past_exam` 후보. 계산 결과 검증 필요

### 2011-4-03. 도시관리계획의 계획내용

- 유형: 단답/서술형
- 주제: 도시관리계획
- 상태: 2020년 도시·군관리계획 계획내용 후보와 중복 가능. 신규 추가 보류

### 2011-4-04. 도시계획시설 또는 도로·공원 관련 문항

- 유형: 단답/서술형
- 주제: 기반시설, 도로, 공원
- 상태: 기존 후보와 중복 가능. 원문 세부 판독 후 분류
