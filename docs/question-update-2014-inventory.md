# 2014년 도시계획기사 실기 기출 업데이트 인벤토리

## 작업 목적

업로드된 2014년 복원문제 이미지 PDF를 기준으로 2014년 자료를 분류한다.

2014년 자료는 복원형·개념형·요약형 자료가 섞여 있을 가능성이 높으므로, 본 기출 데이터에 바로 넣지 않고 `past_exam`, `mock_exam`, `practice`, `summary` 후보로 구분한다.

## 플랫폼 기준 분류

- `past_exam`: 회차·문항 구조·정답이 명확한 실제 복원 기출 후보
- `mock_exam`: 복원자료와 법령·개념을 바탕으로 만든 모의고사형 문제
- `practice`: 개념 암기, 키워드 반복, 계산 연습용 문제
- `summary`: 문제 풀이 후 보는 핵심정리·해설 콘텐츠

## 원칙

1. 원문 구조와 정답이 명확한 문제만 `past_exam` 후보로 둔다.
2. 개념형 요약 자료는 `practice` 또는 `summary` 후보로 분류한다.
3. 2015~2020 후보와 중복되는 문제는 신규 추가하지 않는다.
4. 오래된 법령·제도 문제는 `법령검토필요` 태그를 붙인다.
5. 복원자료 기반 문제는 `기출복원` 태그를 붙인다.

## 2014년 자료 분류

출처: 업로드 PDF 중 2013~2015년 복원문제 묶음.

### 2014-01. 도시계획의 개념과 목적

- 유형: 서술형
- 주제: 도시계획 일반론
- 분류: `practice` 또는 `summary`
- 상태: 실제 기출 원문 확인 전까지 `past_exam`에 넣지 않음

### 2014-02. 도시기본계획과 도시관리계획 구분

- 유형: 단답/서술형
- 주제: 도시·군기본계획, 도시·군관리계획
- 분류: `practice` 또는 `mock_exam`
- 상태: 원문 구조가 명확하면 `past_exam` 후보 가능

### 2014-03. 용도지역·용도지구·용도구역

- 유형: 단답/서술형
- 주제: 국토계획법, 용도체계
- 분류: `practice` 또는 `past_exam 후보`
- 상태: 2017 후보와 중복 가능. 본 데이터 신규 추가 보류

### 2014-04. 기반시설 또는 도시계획시설 종류

- 유형: 단답형
- 주제: 기반시설, 도시계획시설
- 분류: `past_exam 후보`
- 상태: 2016~2020 후보와 중복 가능. 신규 추가 보류

### 2014-05. 도로의 기능별 분류 또는 도로율

- 유형: 단답/표 작성
- 주제: 도로, 도로율, 기능별 분류
- 분류: `past_exam 후보`
- 상태: 2018~2020 후보와 중복 가능. 신규 추가 제외 또는 보강 후보

### 2014-06. 공원·녹지 또는 도시공원 기준

- 유형: 단답형
- 주제: 도시공원, 녹지, 면적기준
- 분류: `past_exam 후보`
- 상태: 기존 2024년 문제 및 2018~2019 후보와 중복 가능

### 2014-07. 인구추정 방법 또는 계산

- 유형: 계산형/단답형
- 주제: 인구추정
- 분류: 수치·조건이 명확하면 `past_exam`, 개념형이면 `practice`
- 상태: 대표 계산문제로 별도 관리 권장

### 2014-08. 도시개발사업 방식

- 유형: 단답형
- 주제: 수용방식, 환지방식, 혼용방식
- 분류: `past_exam 후보`
- 상태: 2016 후보와 중복 가능. 신규 추가 보류

### 2014-09. 정비사업 또는 재개발·재건축

- 유형: 단답형
- 주제: 정비사업
- 분류: `past_exam 후보`
- 상태: 2020 후보와 중복 가능. 신규 추가 보류

### 2014-10. 지구단위계획 및 도시설계

- 유형: 단답/서술형
- 주제: 지구단위계획, 도시설계
- 분류: `practice` 또는 `mock_exam`
- 상태: 2017~2020 후보와 중복 가능. 보강 후보

## 1차 반영 판단

2014년 자료는 현재 단계에서 본 기출 데이터로 바로 반영하지 않는다.

### past_exam 후보

원문·조건·정답 구조가 확인되면 후보화 가능:

- 도시기본계획과 도시관리계획 구분
- 기반시설 또는 도시계획시설 종류
- 도로의 기능별 분류 또는 도로율
- 공원·녹지 또는 도시공원 기준
- 인구추정 계산형
- 도시개발사업 방식
- 정비사업 종류

### practice/mock_exam/summary 후보

원문이 불명확하면 연습문제 또는 핵심정리로 분리:

- 도시계획의 개념과 목적
- 용도지역·용도지구·용도구역 개념
- 지구단위계획 및 도시설계 개념
