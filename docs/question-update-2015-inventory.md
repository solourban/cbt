# 2015년 도시계획기사 실기 기출 업데이트 인벤토리

## 작업 목적

업로드된 2015년 복원문제 이미지 PDF를 기준으로 2015년 기출문제를 CBT 데이터로 전환한다.

## 원칙

1. 2016~2020 후보와 중복되는 문제는 신규 추가하지 않는다.
2. 오래된 법령·제도 문제는 `법령검토필요` 태그를 붙인다.
3. 계산형은 수치와 풀이가 명확한 경우만 후보화한다.
4. 복원자료 기반 문제는 `기출복원` 태그를 붙인다.
