# 2015년 도시계획기사 실기 기출 업데이트 인벤토리

## 작업 목적

업로드된 2015년 복원문제 이미지 PDF를 기준으로 2015년 자료를 분류한다.

단, 이 플랫폼의 기본 목적은 `년도별 복원문제(기출)`과 `CBT` 풀이이므로 원문이 명확하지 않은 요약형·개념형 문항은 기출 데이터에 바로 넣지 않는다.

## 플랫폼 기준 분류

- `past_exam`: 년도별 복원문제(기출). 회차·문제 구조·정답이 확인되는 문제만 등록
- `mock_exam`: 복원자료, 교육자료, 법령자료를 바탕으로 만든 모의고사형 문제
- `practice`: 개념 암기·키워드 반복·계산 연습용 문제
- `summary`: 문제 풀이 후 보는 핵심정리·해설 콘텐츠

## 원칙

1. 실제 회차와 문제 구조가 확인되는 문제만 `past_exam` 후보로 둔다.
2. 원문이 불명확한 개념형 문항은 `practice` 또는 `summary` 후보로 분류한다.
3. 2016~2020 후보와 중복되는 문제는 신규 추가하지 않는다.
4. 오래된 법령·제도 문제는 `법령검토필요` 태그를 붙인다.
5. 복원자료 기반 문제는 `기출복원` 태그를 붙인다.

## 2015년 자료 분류

출처: 업로드 PDF 중 2013~2015년 복원문제 묶음.

### 2015-01. 도시계획의 목표와 역할

- 유형: 서술형
- 주제: 도시계획 일반론
- 분류: `practice` 또는 `summary`
- 상태: 실제 기출 원문 확인 전까지 `past_exam`에 넣지 않음

### 2015-02. 토지이용계획의 역할

- 유형: 단답/서술형
- 주제: 토지이용계획
- 정답 후보:
  - 토지이용의 합리화
  - 기능 배분
  - 용도 간 상충 방지
  - 장래 도시공간구조 유도
- 분류: `practice` 또는 `mock_exam`
- 상태: 실제 문제 원문이 확인되면 `past_exam`, 아니면 연습문제/모의고사 후보

### 2015-03. 도시계획시설 또는 기반시설 분류

- 유형: 단답형
- 주제: 기반시설
- 분류: `past_exam` 가능성 있음

### 2015-04. 공원·녹지 종류 및 기준

## 1차 반영 판단

2015년 자료는 현재 단계에서 본 기출 데이터로 바로 반영하지 않는다.

### past_exam 후보

원문·조건·정답 구조가 확인되면 후보화 가능:

- 도시계획시설 또는 기반시설 분류
- 인구추정 방법 또는 계산
- 도로의 기능 및 분류
- 도시개발사업 또는 정비사업

### practice/mock_exam 후보

원문이 불명확하면 연습문제 또는 모의고사로 분리:

- 도시계획의 목표와 역할
- 토지이용계획의 역할
- 지구단위계획 또는 도시설계 개념
- 개발행위허가 또는 성장관리 개념
- 도시공간구조 또는 생활권계획

## 다음 작업

1. 2015년은 본 데이터 후보 생성 보류
2. 원문이 뚜렷한 문제만 추가 확인
3. 나머지는 `practice` 또는 `mock_exam` 후보로 별도 관리
4. 기출 업데이트는 2020~2016처럼 원문 구조가 명확한 문제 중심으로 계속 진행
