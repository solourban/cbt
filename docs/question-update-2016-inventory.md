# 2016년 도시계획기사 실기 기출 업데이트 인벤토리

## 작업 목적

업로드된 2016년 복원문제 이미지 PDF를 기준으로 2016년 기출문제를 CBT 데이터로 전환한다.

## 원칙

1. 2017~2020 후보와 중복되는 문제는 신규 추가하지 않는다.
2. 반복 계산형은 수치와 정답이 명확한 경우만 후보화한다.
3. 법령명·제도명이 개정되었을 가능성이 있는 문제는 `법령검토필요` 태그를 붙인다.
4. 복원자료 기반 문제는 `기출복원` 태그를 붙인다.

## 2016년 기출 복원문제 주요 후보

출처: 업로드 PDF 중 2016~2018년 복원문제 묶음.

### 2016-01. 도시계획시설의 종류 및 기반시설 분류

- 유형: 단답형
- 주제: 기반시설, 도시계획시설
- 상태: 2020 후보와 중복 가능성 높음. 신규 추가 보류

### 2016-02. 용도지역·용도지구·용도구역

- 유형: 단답/서술형
- 주제: 국토계획법, 용도체계
- 상태: 2017 후보와 중복 가능. 보강 후보

### 2016-03. 도시개발사업 방식

- 유형: 단답형
- 주제: 도시개발사업, 수용방식, 환지방식, 혼용방식
- 상태: 추가 후보

### 2016-04. 개발행위허가 기준 또는 유형

- 유형: 단답/서술형
- 주제: 개발행위허가
- 상태: 기존 2023년 2회 개발행위허가 문제와 중복 가능. 보강 후보

### 2016-05. 인구추정 계산형

- 유형: 계산형
- 주제: 등차급수법, 등비급수법, 최소자승법 등
- 상태: 반복 유형. 수치 판독 후 대표 계산문제로 별도 처리 권장

### 2016-06. 도로의 종류 및 기능별 분류

- 유형: 단답형
- 주제: 도로분류
- 상태: 2020 후보와 중복. 신규 추가 제외

### 2016-07. 공원·녹지 관련 기준

- 유형: 단답형
- 주제: 도시공원, 녹지, 면적기준
- 상태: 기존 2024년 및 2019 후보와 중복 가능. 보류

### 2016-08. 정비사업 또는 도시재생 관련 개념

- 유형: 단답/서술형
- 주제: 정비사업, 도시재생
- 상태: 2020/2019 후보와 중복 가능. 보류

### 2016-09. 지구단위계획구역 또는 지구단위계획 내용

- 유형: 단답/서술형
- 주제: 지구단위계획

### 2016-10. 도시계획의 주민참여 절차
