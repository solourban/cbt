# 2017년 도시계획기사 실기 기출 업데이트 인벤토리

## 작업 목적

업로드된 2017년 복원문제 이미지 PDF를 기준으로 2017년 기출문제를 CBT 데이터로 전환한다.

## 원칙

1. 2018~2020 후보와 중복되는 문제는 신규 추가하지 않는다.
2. 복원형·서술형 문제는 해설과 키워드를 중심으로 CBT화한다.
3. 계산형 문제는 수치와 풀이가 명확한 것만 후보 데이터로 만든다.
4. 법령명·제도명이 개정되었을 가능성이 있는 문제는 `법령검토필요` 태그를 붙인다.
5. 복원자료 기반 문제는 `기출복원` 태그를 붙인다.

## 2017년 기출 복원문제 주요 후보

- 유형: 단답/서술형
- 주제: 인구추정
- 정답 후보:
  - 등차급수법
  - 등비급수법
  - 최소자승법
  - 로지스틱곡선법
  - 집단생잔법
  - 사회적 증가분 반영
- 상태: 추가 후보
- 비고: 계산형보다 개념형으로 먼저 등록 권장

### 2017-02. 도시공원 또는 녹지 확보 기준

- 유형: 단답/표 작성
- 주제: 도시공원, 녹지, 개발계획 규모별 확보 기준
- 상태: 2018/2019 후보와 중복. 보류

### 2017-03. 도로 기능별 분류 및 곡선반경

- 유형: 단답/표 작성
