# 2018년 도시계획기사 실기 기출 업데이트 인벤토리

## 작업 목적

업로드된 2018년 복원문제 이미지 PDF를 기준으로 2018년 기출문제를 CBT 데이터로 전환한다.

## 원칙

1. 2019·2020 후보와 중복되는 문제는 신규 추가하지 않는다.
2. 반복 출제되는 기본 암기형은 대표 문제로만 관리한다.
3. 법령명·제도명이 개정되었을 가능성이 있는 문제는 `법령검토필요` 태그를 붙인다.
4. 복원자료 기반 문제는 `기출복원` 태그를 붙인다.

## 2018년 제1회 기출 복원문제 후보

출처: 업로드 PDF `pdf24_converted3.pdf` 후반부.

### 2018-1-01. 지구단위계획 수립 시 고려해야 할 사항

- 유형: 단답/서술형
- 주제: 지구단위계획 수립 기준
- 상태: 원문 일부 판독 필요. 보류

### 2018-1-02. 인구추정

- 유형: 계산형
- 주제: 등차급수법, 등비급수법
- 상태: 2011~2020 자료에 반복되는 계산 유형. 대표 문제로 관리 권장

### 2018-1-03. 개발계획 규모별 도시공원 또는 녹지 확보 기준

- 유형: 단답/표 작성
- 주제: 도시공원, 녹지 확보 기준
- 상태: 2019년 후보와 중복. 보강 대상으로 검토

### 2018-1-04. 도로 기능별 구분 및 곡선반경

- 유형: 단답/표 작성
- 주제: 주간선도로, 보조간선도로, 집산도로, 국지도로, 특수도로
- 상태: 2020/2019/2023 문제와 중복. 신규 추가 제외 권장

- 주제: 교통광장, 역전광장, 주요시설광장

- 상태: 추가 후보. 기존 데이터와 중복 가능성 낮음

- 유형: 단답형
- 주제: 주거환경개선사업, 재개발사업, 재건축사업
- 상태: 2020 후보와 중복. 신규 추가 제외 또는 기존 후보 보강

### 2018-2A-03. 로지스틱 곡선법 인구추정

- 유형: 계산형
- 주제: 인구추정, 로지스틱 곡선법
- 상태: 계산형으로 가치 있으나 수식/수치 확인이 필요. 보류

### 2018-2A-04. 우수유출량 계산

- 유형: 계산형
- 주제: 합리식, 우수유출량
- 상태: 2020/2019 후보와 동일. 신규 추가 제외

### 2018-2A-05. 국토계획평가제도

- 유형: 단답/서술형
- 주제: 국토계획평가
- 상태: 기존 데이터와 중복 가능성 확인 필요. 추가 후보
