# 2020년 도시계획기사 실기 기출 업데이트 인벤토리

## 작업 목적

업로드된 복원문제 이미지 PDF를 기준으로 2020년 기출문제를 CBT 데이터로 전환한다.

## 원칙

1. 기존 `questions.js`와 동일·유사한 문제는 중복 추가하지 않는다.
2. 중복 문제는 기존 문제의 해설·키워드 보강 대상으로 분류한다.
3. 단답형·빈칸형은 `short_answer` 또는 `subs` 구조로 등록한다.
4. 계산형은 `calculation` + `steps` 구조로 등록한다.
5. 복원자료 기반 문제는 `기출복원` 태그를 붙인다.
