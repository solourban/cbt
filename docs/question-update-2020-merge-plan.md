# 2020년 기출 본 데이터 병합 계획

## 목적

`src/data/updates/questions-2020.js`에 정리한 2020년 기출 후보를 기존 `questions.js`와 비교하여 본 데이터에 반영할 항목을 확정한다.

## 분류 기준

### A. 본 데이터 신규 추가

기존 문제와 출제 주제·정답 키워드가 뚜렷하게 다르며, CBT에서 독립 문항으로 가치가 있는 문제.

### B. 기존 문제 보강

기존 문제와 핵심 정답이 같거나 거의 같지만, 해설·태그·보너스 키워드를 보완할 가치가 있는 문제.

### C. 보류

법령개정 반영이 필요하거나 원문 판독이 불확실한 문제.

## 병합 방식 제안

### 현 단계

현재 정적 앱은 루트 `questions.js`를 사용한다. 그러나 Vite 전환 작업이 병행 중이므로 바로 루트 `questions.js`를 대형 수정하면 충돌 가능성이 높다.

### 권장 방식

1. `src/data/updates/questions-2020.js`는 후보 데이터로 유지
2. Vite 전환 후 `src/data/questions.js`와 병합
3. 정적 앱에 즉시 반영해야 할 경우 별도 스크립트로 `QUESTIONS` 배열 끝에 삽입
4. 병합 전 ID 충돌 검사 실행
