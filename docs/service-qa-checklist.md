# 도시계획기사 CBT 서비스 전체 QA 체크리스트

## 목적

이 문서는 기출 업데이트만이 아니라 서비스 전체 기능을 한 번씩 실제로 눌러보며 오류를 수집하기 위한 QA 기준이다.

개별 오류를 발견할 때마다 즉시 수정하지 않고, 먼저 오류를 모아 유형별로 분류한 뒤 한 번에 수정한다.

---

## 테스트 원칙

1. 기능을 하나씩 끝까지 눌러본다.
2. 오류가 나면 즉시 코드 수정하지 않고 기록한다.
3. 같은 유형 오류는 묶어서 처리한다.
4. 테스트는 모바일 화면과 PC 화면을 모두 확인한다.
5. 채점 오류는 문제 데이터 오류와 채점 함수 오류를 구분한다.
6. 배포 화면 기준으로 먼저 확인하고, 필요 시 로컬 빌드로 재현한다.

## 테스트 완료 기준

1차 완성 기준은 다음을 모두 만족해야 한다.

1. 홈 화면과 주요 기능 진입이 정상이다.
2. 기출/모의고사/드릴/OX/플래시카드가 최소 1회 이상 실행된다.
3. 채점 버튼 무반응 오류가 목록화되어 있다.
4. 치명적 오류 없이 전체채점과 결과 저장이 가능하다.
5. Vercel 배포 화면에서 기존 문제와 신규 후보가 모두 표시된다.
6. 발견된 오류가 별도 이슈 목록으로 정리되어 있다.
